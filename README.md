# TES Container Viewer

Orbitable 3D viewer of the Trinium Energy System 40 ft container concept: process wall on the front, electrolyte and fuel storage on the back.

Drag to orbit, scroll to zoom. Camera presets cover front, back, isometric, end, utility, and top. Cutaway, x-ray, explode, and wall isolation match the concept sheet.

## Scripts

```bash
npm install
npm run dev
npm run build
```

Dev server listens on port 8080. Auth and database are off; the viewer does not need an account.
